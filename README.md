# RIPPLE — Viral Habit-Chain Product (Prototype)

Ripple is a viral, habit-building app designed around **chain reactions**.  
One good action triggers another — for yourself, friends, and community.

This prototype was built for the **Viral Product Design exercise**, focusing on:
- Organic growth loops  
- Retention and re-engagement  
- High-clarity UX  
- Metric-driven behaviour design

## 🔥 Problem
Most habit-building apps fail because:
- Habits fade when motivation drops  
- Users feel isolated  
- Tracking becomes boring  
- No social or emotional reward  

Ripple solves this by making habits **contagious** through social chain reactions.

---

## 💡 Solution
Ripple introduces:
- **Habit Chains** — each habit completed triggers an animation + a chain reaction ripple.
- **Spark Invites** — users send "micro-challenges" to 1–3 friends.
- **Streak Insurance** — friends can “boost” your streak when you’re about to fail.
- **Community Ripple Meter** — combined progress of all users creates a global visual meter.

These systems create **retention + viral loops** naturally.

---

## 🌀 Viral Growth Loop (CORE FEATURE)
1. User completes a habit  
2. Ripple animation appears → “Send this ripple to 3 friends?”  
3. Friend receives a micro-challenge  
4. Friend joins to complete it  
5. New user now sends micro-challenges to others  

This creates infinite natural growth.

---

## 📊 Monetisation
**Ripple Boosts (₹49–199):**
- Unlock special chain animations  
- Add premium streak insurance  
- Personalized challenges from creators  

---

## 📈 Primary Metric (North Star)
**DAU × Chain Reactions Sent per User (CRPU)**  

This measures engagement + viral spread at once.

---

## 🧭 User Journey
1. User signs up with phone/email  
2. Selects 3 micro-habits (60 seconds setup)  
3. Completes first habit → sees ripple animation  
4. Sends ripple to friends  
5. Joins community ripple meter  
6. Unlocks streak insurance  
7. Converts to paid booster after 7 days
