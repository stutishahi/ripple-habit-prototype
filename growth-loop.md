# Viral Growth Loop — RIPPLE

## 1. Trigger
User completes a habit → ripple effect plays.

## 2. Action
User gets CTA: “Send this ripple to 3 friends?”

## 3. Incentive
Unlock:
- Bonus streak day
- Ripple badge
- Bigger chain animation

## 4. Friend Receives
A micro-challenge:
“You’ve been sent a ripple. Complete one action to pass it forward.”

## 5. Conversion
Friend joins the app.

## 6. Compounding Loop
Friend now sends ripples → exponential organic growth.
